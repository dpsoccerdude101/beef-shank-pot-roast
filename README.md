# Beef Shank Pot Roast

A phone-first, ad-free cooking page for one **4.72 lb bone-in beef shank**, adapted from
[Spend With Pennies' Perfect Pot Roast](https://www.spendwithpennies.com/perfect-pot-roast/).

**Live:** https://dpsoccerdude101.github.io/beef-shank-pot-roast/

## Why it differs from the source

- **4.72 lb bone-in yields 3.2 to 3.5 lb of meat**, so the seasoning stays at a normal batch and does not scale to 4.72.
- **Shank braises longer.** The original's 2 + 2 hours targets chuck. Shank is collagen-heavy and lean, so it needs 2.5 + 1.5 to 2 hours, 4 to 4.5 total.
- **More liquid.** 3 cups broth and 1.5 cups wine instead of 2 and 1, because the cook is longer and the pot is fuller.
- **Tomato paste and a wine reduction** are added for depth the original does not call for.
- **Less thickener.** Shank drippings gel on their own, so the gravy starts at 1 tbsp cornstarch rather than 2.

## Features

- Cut toggle: bone-in 4.72 lb, or meat-only if the bone was removed
- Conventional / convection toggle, 300F against 275F, with the covered-pot note
- Ingredient checklist with progress bar, saved only for the session
- Braise timer that resets with the cut
- No dependencies, no network calls, single file

## Deploy

Static GitHub Pages from `main`, root of the repo. One `index.html`, nothing to build.
